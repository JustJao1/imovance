# Imovance

Property management and operations platform for rental businesses and property managers.

[Live interactive demo](https://imovel-em-dia-portfolio.vercel.app) · Portfolio release 7.2

The demo uses fictional browser-local data, requires no account, and does not process real payments. The interface is in Brazilian Portuguese.

The web interface is available in `static/`. The Python backend and tests are part of the full release package and are being transferred separately.

No general reuse license has been selected.
