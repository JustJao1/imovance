# Imovance

Property management and operations platform for rental businesses and property managers.

[Live interactive demo](https://imovel-em-dia-portfolio.vercel.app) · Portfolio release 7.2

The demo uses fictional browser-local data, requires no account, and does not process real payments. The interface is in Brazilian Portuguese.

## Features

- Property workspaces, inventory, maintenance, cleaning and purchasing.
- Reservation management, receivables and financial tracking.
- Responsive dark interface and keyboard-accessible module search.

## Repository status

The interactive web interface is being published here. The independent Python and SQLite backend and its automated tests are part of the full release package but are not yet present in this repository. No general reuse license has been selected.
